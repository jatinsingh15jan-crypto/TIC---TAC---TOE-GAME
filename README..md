# TIC TAC TOE GAME 

this my tic tac toe project. it is a single player game , so you play against the computer. i made it using HTML,CSS and JAVASCRIPT.

## ABOUT THE GAME 

you aree X and the computer is O  . you always play first. if you get three in a row you win. the game also keeps a score of your wins, the compter's wins and draws.
The computer is not random . it first checks if it can win, then it tries to block yoiu , and after that it picks te centre or a corner .

## HOW TO PLAY 

1. click on any empty boc to put your X.
2. The computer will put its O after that.
3. Whoever gets 3 in a row firt wins.
4. Press the New Game button to play again.
